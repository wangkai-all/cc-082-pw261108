# 知味小厨 · 餐饮配方成本试算页

纯前端单页应用（原生 ES Module，无构建步骤、无外部依赖），维护菜品配方、食材采购批次、
损耗率与售价，试算每份成本与毛利，并支持价格情景对比与食材替换对照。

## 运行

```bash
npm start          # 启动静态服务器 http://localhost:4173
npm test           # 运行计算引擎与页面渲染测试（node:test，28 例）
```

直接用浏览器打开 `index.html` 亦可（需通过 http 访问，ES Module 不支持 file://）。
数据保存在 localStorage，修改后可用页面右上角「重置示例数据」恢复内置虚构数据。

## 四个页签

| 页签 | 功能 |
|---|---|
| 菜单试算 | 菜品列表（售价 / 每份成本 / 毛利 / 毛利率 / 相对基准的 Δ）；进入详情可调整用量与售价、增删食材行、替换食材，保存即生成新配方版本 |
| 食材与采购 | 食材的可食比例、损耗率、包装规格、过敏原；展开查看全部采购批次（旧报价保留）、追加新批次、把某一批次「指定」为试算价格 |
| 价格情景 | 情景切换与自定义（加权 / 最新 / 指定批次 / 模拟涨跌%）；各菜品毛利率「基准 vs 情景」对比图与对照表 |
| 销售统计 | 历史销量按**销售时的配方版本**统计，单份成本取销售当日及之前批次的加权价 |

## 计算口径

- **净料 / 毛料**：配方用量一律按净料（可食部）录入；采购批次按毛料（采购状态）录入。
- **单位换算**：质量（g/kg）直接换算；体积（ml/L）经食材密度（g/ml）折克；计数（个）经单件净重折克；包装单位（箱/袋/桶/瓶/板/盒/包/捆）经包装规格折毛料克。
- **单行成本**：`净料克 ÷ 可食比例 ÷ (1 − 损耗率) × 批次单价(元/毛料克)`。
- **批次单价**：`批次总价 ÷ 批次数量折毛料克`。加权成本 = Σ总价 / Σ毛料克（全部在录批次）。
- **价格情景**：指定批次 > （加权 | 最新），再叠加模拟涨跌%。基准固定为「加权平均成本」。
- **毛利**：毛利 = 售价 − 成本；毛利率 = 毛利 ÷ 售价。
- **历史成本**：销售当日及之前批次的加权价（当日之前无批次则取全部批次）。

## 食材替换（不只按重量换算）

替换流程要求显式确认换算，而非 1:1 照搬原单位数值：

1. 以原行的**净料克重**为锚（30ml 油 → 27.6g，经密度；3 个鸡蛋 → 150g，经单件净重）；
2. 用户确认**换算比率**（如干香菇→鲜香菇约 1:5~1:6 泡发增重）与**目标单位**；
3. 对照面板并列展示原/新食材的单位、净料、毛料、单位成本、单份小计与**过敏原差异**
   （新增红色警告 / 移除绿色 / 保留中性），并预演新配方的成本与毛利率；
4. 确认后应用到草稿，「保存为新版本」才生效——历史版本与历史销量统计不受影响。

## 目录结构

```
index.html          页面骨架
css/styles.css      样式（亮/暗两套设计令牌）
js/units.js         单位体系与换算（质量/体积/计数/包装）
js/costing.js       成本引擎（纯函数）：批次价、加权/最新/指定批次、配方成本、毛利、历史成本
js/data.js          虚构示例数据（菜单、26 种食材、40+ 采购批次、21 条月度销量、4 个情景）
js/store.js         状态与 localStorage 持久化（Node 下退化为内存，便于测试）
js/app.js           渲染与事件委托
server.mjs          极简静态服务器（无依赖）
test/               node:test 单元测试与无头渲染冒烟测试
```

## 已知边界（有意简化）

- 不跟踪批次剩余库存与出库，加权成本按全部在录批次计算；
- 销量为按月汇总记录，无逐单流水；
- 损耗率为食材级（配方行可覆盖的口子已留在 `line.lossRate`）；
- 所有店名、供应商、价格均为虚构。
